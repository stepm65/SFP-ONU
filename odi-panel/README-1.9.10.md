# ODI Panel 1.9.10

Исправлено оформление встроенных страниц по скриншоту устройства с 1.9.9.

- Таблицы состояния, PON, LAN/IP, диагностики и системных настроек занимают ширину окна. Убраны старые фиксированные размеры, серые заливки и пустые разделители.
- Шрифт таблиц соответствует таблицам основной панели: 12 px, системный шрифт; поля ввода — 14 px. Встроенные страницы используют стандартный режим HTML вместо режима совместимости.
- Заголовки групп и строки данных оформлены в стиле основной панели. Убраны повторяющаяся служебная подпись и ссылка «Открыть отдельно» над каждым окном. Резервный интерфейс остаётся в разделе восстановления доступа.
- Переведены CPU Usage и Memory Usage. Версия страницы, API, входа и ресурсов обновлена до 1.9.10.
- Предпросмотр использует ту же обработку таблиц, что и прошивка.

Проверено: сохранность форм, полей, обработчиков и черновиков на 18 страницах; регрессии JavaScript; отображение девяти разделов в Chromium при ширине 390 и 1440 px. Браузерная проверка использует файлы из собранного SquashFS, подставные значения ASP и отключённые заводские инициализаторы. На физическом ONU новая версия ещё не проверена.

Сообщённый обрыв загрузки на этапе проверки архива в новом интерфейсе этим выпуском не исправляется. Для установки используйте **TAR через legacy-интерфейс**, которым уже удалось обновить устройство. ZIP содержит TAR, исходники, документацию и предпросмотр.

Основа: ODI SFU V1.1.8-240408, RTL9601D, X100SFP. Проверка образа и ограничения разделов сохранены. Ядро и заводской установщик не изменены.
