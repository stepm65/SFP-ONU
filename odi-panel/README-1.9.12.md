# ODI Panel 1.9.12 — SFU 240408

- Фоновый журнал подключения: два файла по 32 КиБ в RAM, ротация, чтение, скачивание и очистка в панели.
- Syslog по TCP: IPv4/порт/имя стика, сохранение без перезагрузки, кнопка теста. RFC 5424 и RFC 6587 octet counting; UDP/TLS не поддерживаются.
- Запуск обработчика, идентификатор загрузки, переходы PON, режим SFP, результат мода, минутный heartbeat. Нет паролей и полных OMCI-трасс. Локальная история очищается после перезагрузки; удалённая доставка не гарантирована при недоступности сети.
- Профили: название и описание, группы параметров, выбор изменений, отдельный выбор личных данных и режима порта.
- Один основной экран с кнопкой «Панель диагностики» вместо переключения компактного и диагностического режимов.
- Раздел «MikroTik / RouterOS» вместо привязки к RB5009.

Настройка журналирования: `docs/06-CONNECTION-LOGGING-RU.md`.

Установка через legacy. Обрыв нового загрузчика на проверке архива остаётся отдельной нерешённой проблемой.

Новые функции проверены на компьютере. Испытания на физической ONU и Eltex OLT ещё не проведены. Сборка не заявляет исправление причины потери O5.
