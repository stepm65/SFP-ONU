# Состав сборки

Основа — ровно предоставленный M110_sfp_ODI_SFU_240408.tar, SHA256
`79c5ce4e62f4cb334b4335ad405d14f8c905b8b61d56ca636486d1ef91632623`.
Сведения о патчах относятся к включённым исходникам, а не к любому проекту с похожим названием.

| Компонент | Статус | Что изменено / ограничения |
|---|---|---|
| Anime4000 `fix_speed.sh` | Адаптирован, выключен по умолчанию | Ограничения ingress/egress; используется ключ LAN_SPEED_MODE этой основы |
| Anime4000 `fix_sw_ver.sh` | Адаптирован, выключен по умолчанию | В режиме OMCI 3 — пользовательские версии, при пустых полях версии банков |
| Anime4000 `fix_vlan_tag.sh` | Адаптирован, выключен по умолчанию | Обработка ME 84 по указанным VLAN/Entity ID; пустой фильтр не разрешает массовую запись |
| Anime4000 `fix_vlan_fwdop.sh` | Адаптирован, выключен по умолчанию | Пары Entity ID:FwdOp; точное совпадение; взаимоисключение с предыдущим алгоритмом |
| Пользовательские OMCI-версии | Собственная интеграция | Ранний загрузочный хук; при отключённом моде задаются только явно заполненные версии |
| Hack GPON | Документация, не отдельный пакет кода | Настройки идентичности и банков сопоставлены с нашей основой; факт переноса самостоятельного набора бинарных патчей не установлен |
| OLT mode 21 | Не включён | Используем проверяемые значения 0–3; обход с mode 21 не предлагается |
| Boa CGI | Включён | Точная маршрутизация CGI и передача признака администратора из штатной таблицы сессий |
| Чужие OMCI/ядро/драйверы | Не заменены | Сохранены из пользовательской основы; весь upstream firmware mod не импортирован |
| MACKEY | Включён | Локальный алгоритм указанного пользователем ODI-tools; проверен на 64 контрольных примерах |
| Интерфейс RU/EN | Включён | Общая авторизация GPON/EPON, PLOAM ASCII/HEX, OUI, Fiber Reset, штатные разделы |
| Запись в банк | Включена | Явный неактивный банк, строгая совместимость, проверка до записи и чтение обратно |
| Совместимость с BusyBox стика | Включена | В прошивке нет `mv`, `tr`, `head`, `od`, `rmdir` и др.; скрипты используют только команды из `source/device-commands.txt` |

Исходники Anime4000 зафиксированы на commit
`ad2fde9df058e3fa70b8b079ae5bcd308d41e394`, каталог
`Firmware_Mod/DFP-34X-2C2/etc/scripts`.
Оригиналы, лицензия и хеши находятся в `source/upstream`; адаптации —
`source/src/anime`. Это четыре конкретных скрипта, не обещание включения всех
изменений из репозитория. В upstream-комментариях сохранены имена авторов.

Отсутствие отдельного набора Hack GPON исправляет прежнюю неоднозначную формулировку
«патчи сохранены». Сохранены перечисленные исходники и функции; непроверенные
бинарные изменения не приписываются сборке.

Источники:
- https://github.com/Anime4000/RTL960x/tree/ad2fde9df058e3fa70b8b079ae5bcd308d41e394/Firmware_Mod/DFP-34X-2C2
- https://hack-gpon.org/ont-odi-realtek-dfp-34x-2c2/
- https://odi-tools.dextercai.com/

Важное отличие конкретной основы: загрузочный скрипт SFU 240408 использует
LAN_SPEED_MODE. Одноимённые рекомендации для другой версии прошивки нельзя
переносить только по названию стика.
