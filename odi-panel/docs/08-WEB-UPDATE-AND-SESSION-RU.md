# Обновление и веб-сессия

Открывайте панель по `http://<адрес стика>/`. После успешного открытия вложенной ссылки адрес нормализуется до `/#раздел`.

## Запись прошивки

Обновление выполняется в неактивный банк. Панель проверяет TAR, базовое ядро, установщик, аппаратный тег, контрольные суммы и разметку flash. Затем фоновый процесс записывает образ и сравнивает flash с содержимым TAR. Успех требует статуса `VERIFIED bank=N` именно для текущей операции; прежний статус не подтверждает новую загрузку.

Выбор банка для загрузки и перезагрузка выполняются отдельно. Если связь прервалась, не повторяйте запись сразу. Проверьте `/tmp/odi-panel/firmware-status`, `firmware-phase`, `firmware-error` и `firmware-update.log`. Временные ошибки опроса повторяются; после длительной потери связи результат остаётся неподтверждённым. В ответе API показываются последние 2048 байт журнала, полный файл сохраняется в RAM до перезагрузки.

Заводская страница через `/legacy.html` остаётся доступной для совместимых устройств. Она не выполняет дополнительные проверки панели и не снимает её маркер непроверенного банка. Если такой маркер установлен, сначала проверьте содержимое банка.

## Вход и выход

Кнопка выхода отправляет штатный POST в `/boaform/admin/formLogout` и проверяет, что корневой адрес возвращает страницу входа. Затем браузер открывает `/`. Промежуточная страница `/admin/logout.asp` не используется. При несохранённых изменениях появляется одно подтверждение. При ошибке связи выход не считается подтверждённым; доступна ссылка на корневую страницу входа.

Если сессия истекла, откройте `/`, войдите и вернитесь к панели. Переключение RU/EN не перезагружает формы и не удаляет черновики.

## Проверки

Программные проверки включают форму обновления, фоновый протокол, ограничение журнала, навигацию, сохранение полей при смене языка и выход с имитацией ответа штатного обработчика. Они не заменяют проверку авторизации и flash на устройстве.
