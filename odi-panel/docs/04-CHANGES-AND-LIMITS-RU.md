# Применение настроек и ограничения

Когда вступают в силу изменения из разных разделов панели и что при этом учитывать. Изменения текущей версии — в README-1.9.7.md.

| Изменение | Когда действует | Что учитывать |
|---|---|---|
| RU/EN | Немедленно в браузере | Сохраняется локально; flash не изменяется |
| PLOAM ASCII/HEX | Отображение сразу; запись кнопкой формы | Байты сохраняются при переключении; только 10 печатных ASCII либо 20 HEX |
| LOID/пароль | Запись в общие параметры GPON/EPON | Отдельных дублирующих полей EPON нет |
| SN, PLOAM, OUI, OMCI-профиль | Сохраняются отдельно; применять после перезагрузки | Нельзя обещать повторную регистрацию PON без проверки с OLT |
| Пользовательские версии ПО | При загрузке в OMCI mode 3 | Старый хук и мод версий одновременно не применяются |
| VLAN и режим SFP | После отдельной перезагрузки | Ошибка может лишить связи; возможность 2,5G зависит от порта |
| Моды Anime4000 | После перезагрузки | По умолчанию отключены; изменения OMCI в памяти не всегда обратимы без перезапуска |
| MACKEY | Расчёт сразу локально, запись отдельно | Записывайте ключ вместе с MAC, для которого он рассчитан |
| Fiber Reset | Сохраняется штатным обработчиком | Кнопка не выполняет сброс; не проверяйте функцию случайными переподключениями оптики |
| Выбор банка | Следующая загрузка | Не копирует и не записывает прошивку |
| Установка TAR | Сразу пишет указанный неактивный банк | Не переключает загрузку и не перезагружает автоматически |
| Восстановление конфигурации / сброс | Штатный обработчик | Критические сохраняемые поля определяет заводская реализация |

Установка прошивки: явный целевой банк, проверки совместимости, защита работающего
банка, чтение записанных данных обратно, отметка непроверенного банка, сообщения RU/EN.

Покрытие перевода: собственные страницы и все multilang-ID в 18 основных штатных
шаблонах; также найденные строковые уведомления ping/WAN. Отчёт указывает область
покрытия. Не обещается перевод каждого скрытого шаблона универсального Realtek SDK
(WLAN/DSL/VPN) или ещё не наблюдавшегося ответа бинарного сервера. Названия протоколов,
ключи конфигурации, технические логи и идентификаторы остаются исходными.

Авторизация CGI панели: штатная сессия Boa не заполняет REMOTE_USER, поэтому
веб-сервер сам находит запись входа администратора в таблице
сессий и передаёт этот признак CGI панели. Подделать его из HTTP-запроса нельзя.
