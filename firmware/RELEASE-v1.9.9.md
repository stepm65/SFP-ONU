# ODI Panel 1.9.9

Исправления встраивания штатных страниц, версии интерфейса и переключения языка.

- Состояние устройства/PON, LAN/IP, ARP, ping, статистика, пароль и таймер используют отдельные ASP-страницы в `/panel/odi-native-*.asp`. Заводские обработчики POST и проверки полей сохранены. Относительные ресурсы разрешаются от корня, возврат из формы и автообновление ведут на встроенную страницу.
- При получении оболочки, frameset или страницы входа вместо формы панель останавливает её отображение и предлагает повторный вход. Дублирующий заголовок штатной страницы скрыт только во встроенном режиме.
- Штатный блок English/Chinese заменён выбором **Русский / English**. Он синхронизируется с верхним переключателем, сохраняется в браузере и не меняет заводскую настройку языка через POST.
- Футер получает версию из API работающей прошивки. При несовпадении с версией загруженной HTML-страницы появляется ссылка на свежий интерфейс. Начальный переход на панель также содержит номер версии.

Образ: `ODI-Panel-1.9.9-RU-EN-SFU-240408.tar`; SHA256 — в `firmware/SHA256SUMS`. Отчёты: `firmware/reports/1.9.9/`.

Проверки интерфейса выполнены в jsdom, структура итогового образа и формы проверены при сборке. Работа новых встроенных маршрутов на реальном ONU ещё требует проверки. Исправление O5 на Eltex OLT не подтверждено; профиль Eltex из 1.9.8 сохранён.

## Установка

Только для RTL9601D с базой **ODI SFU V1.1.8-240408**, тегом X100SFP, k0/k1 `0x14c000`, r0/r1 `0x274000`. Сохраните конфигурацию и следуйте [инструкции установки](docs/03-INSTALL-AND-RECOVERY-RU.md). Загружайте **TAR**, ZIP содержит также исходники и отчёты.

После переключения на новый банк и перезагрузки откройте `/panel/index.html?v=1.9.9` и выполните Ctrl+F5. Если версия API/диагностики остаётся старой, проверьте работающий банк: очистка кеша не меняет запущенную прошивку.

Разделы из замечаний проверьте повторно, включая обновление статуса и возврат после сохранения формы. Смена языка не должна сбрасывать введённые значения LAN/IP.
