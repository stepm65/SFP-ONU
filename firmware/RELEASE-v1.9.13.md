# ODI Panel 1.9.13 — отладка и обновление прошивки

- Из раздела «Система» убраны дубли Logout и языка интерфейса. Кнопки в верхней панели сохранены.
- Добавлен отдельный полный режим отладки: RAW OMCI, расшифрованный журнал SDK и снимок паролей/идентификаторов без маскирования. Сеанс длится 1/3/5/10 минут, файлы ограничены по объёму и хранятся в RAM. Доступны однократный запуск перед OMCI при следующей загрузке и скачивание PRIVATE TAR.
- Передача RAW OMCI и паролей на настроенный TCP syslog включается отдельно. Обычный журнал остаётся без секретов. PRIVATE-архив и полный syslog содержат настоящие пароли.
- Обновление из новой панели переведено в фоновый процесс: приём TAR, проверка, запись неактивного банка и сравнение с flash. Проверка архива больше не хранит отдельные полные копии ядра и rootfs. После обновления страницы можно продолжить наблюдение. Загрузочный банк автоматически не переключается.
- Главный интерфейс теперь открывается по `/`; активные старые ссылки переводятся на этот адрес. Добавлены повторный вход с сохранением открытой формы и новые даты веб-файлов для обновления браузерного кэша.

Для установки этой версии из старой сборки используйте заводскую страницу обновления через `/legacy.html`: исправление нового загрузчика начнёт действовать после установки 1.9.13. После загрузки откройте `http://192.168.1.1/` и обновите закладку.

Проверены shell/CGI, приём и фоновая запись на файловой модели MTD, отрицательные сценарии архива, приватный экспорт, передача тестовых данных на локальный TCP-приёмник, интерфейс и Chromium. Реальная запись flash, FIFO с нативным OMCI и длительный тайм-аут Boa требуют проверки на стике. Старая глубокая ссылка с уже истёкшей сессией может по-прежнему потребовать первого входа через `/`.
